# Books

This is a Git repository of all my books I have saved locally. I am paranoid that something will happen to my computer that will make me lose all of the books I found helpful. This is a way to keep them alive should something happen to my computer.

If being multi-planetary will preserve the light of human consciousness, then making my digital books multi-repository will preserve their existence. It's a no-brainer.

---

## Repository Structure

### Engineering/
Contains technical and applied books organized by engineering discipline.

| Folder                        | Description |
|------------------------------|-------------|
| `Aerospace-Engineering/`     | Aerodynamics, rocket propulsion, astrodynamics, and space-related engineering |
| `Chemical-Engineering/`      | Inorganic chemistry and foundational chemical engineering topics |
| `Civil-Engineering/`         | Water treatment, desalination, tunnel engineering, and infrastructure-related topics |
| `Computer-Science/`          | Machine learning, programming, algorithms, and computer science fundamentals |
| `Electrical-Engineering/`    | Core electrical engineering topics (contains subfolders: `Motors/`, `Energy-Storage/`, and `Photovoltaics/`) |
| `Manufacturing-Engineering/` | Manufacturing processes, materials processing, casting, machining, and industrial production |
| `Mathematics/`               | Engineering mathematics, calculus, differential equations, and applied math |
| `Mechanical-Engineering/`    | Core mechanical topics including strength of materials, thermodynamics, fluid mechanics, and design (contains `Feedback-Control/`) |

### Physics/
Contains university-level and advanced physics textbooks, grouped by subject.

| Folder                    | Description |
|---------------------------|-------------|
| `Classical-Mechanics/`    | Newtonian mechanics, Lagrangian/Hamiltonian mechanics, and related topics |
| `Electrodynamics/`        | Classical electrodynamics and electromagnetic theory |
| `Mathematical-Methods/`   | Mathematical methods for physicists (including computational physics and thermal physics) |
| `Quantum-Mechanics/`      | Quantum mechanics textbooks and references |
| `Optics/`                 | Optics, photonics, and optical physics (including solar cell physics) |

## Notes
- All `.pdf` and `.epub` files are tracked using Git LFS (via pattern matching in the root `.gitattributes`).
- We track **all** PDFs and EPUBs regardless of file size.
